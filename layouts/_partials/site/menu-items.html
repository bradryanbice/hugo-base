Active state follows the two standard cases: the entry for the page you are on gets aria-current="page", and an entry whose section contains that page gets aria-current="true". Screen readers announce the first as the current page and the second as current within a set, which is the distinction a reader needs. An entry with no URL (a parent used only for grouping) renders as text rather than as a link, because a link to nowhere is a trap for keyboard and screen reader users. */ -}} {{- $menuID := .menuID -}} {{- $page := .page -}}
